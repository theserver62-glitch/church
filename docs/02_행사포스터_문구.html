2. 행사 종류별 문구 예시

A. 여름/겨울 수련회

  • 예시 1 (주제 중심)
  • 메인 타이틀: 다시, 복음 앞에 (Re:Light)
  • 서브 타이틀: 말씀으로 세상을 밝히는 (교회명) 여름 수련회
  • 성구: 마태복음 5:14-16
  • 예시 2 (관계/친교 강조)
  • 메인 타이틀: 우리, 함께 걷다
  • 서브 타이틀: 은혜 안에서 하나 되는 행복한 동행
  • 성구: 에베소서 4:3
  • 예시 3 (도전/비전 강조)
  • 메인 타이틀: 거룩한 모험: 믿음의 발걸음
  • 서브 타이틀: 하나님이 계획하신 꿈을 향하여
  • 성구: 여호수아 1:9

B. 사랑나눔 바자회

  • 예시 1 (이웃 사랑 강조)
  • 메인 타이틀: 이웃과 함께하는 사랑의 바자회
  • 서브 타이틀: 작은 나눔, 커지는 기쁨
  • 성구: 사도행전 20:35
  • 예시 2 (선교/구제 목적 강조)
  • 메인 타이틀: [선교명]을 위한 나눔 장터
  • 서브 타이틀: 우리가 모은 사랑이 복음의 씨앗이 됩니다
  • 성구: 갈라디아서 6:10
  • 예시 3 (축제 분위기 강조)
  • 메인 타이틀: (교회명) 오픈 마켓 & 푸드 페스티벌
  • 서브 타이틀: 맛있는 음식과 따뜻한 마음이 있는 곳으로 초대합니다
  • 성구: 히브리서 13:16

C. 전도 축제 (새생명 축제)

  • 예시 1 (초청 중심)
  • 메인 타이틀: 당신을 기다립니다
  • 서브 타이틀: 쉼과 위로가 있는 (교회명)으로의 초대
  • 성구: 마태복음 11:28
  • 예시 2 (복음 중심)
  • 메인 타이틀: 가장 아름다운 선물, 복음
  • 서브 타이틀: 우리 삶의 가장 기쁜 소식을 함께 나누고 싶습니다
  • 성구: 로마서 1:16
  • 예시 3 (관계 중심)
  • 메인 타이틀: 소중한 당신, 곁에 있어 감사합니다
  • 서브 타이틀: (교회명) 전도 축제에서 만나는 특별한 행복
  • 성구: 요한일서 4:11

D. 성탄 축하 행사

  • 예시 1 (예배 중심)
  • 메인 타이틀: 메리 크리스마스: 구주 나셨네
  • 서브 타이틀: 하늘에는 영광, 땅에는 평화
  • 성구: 누가복음 2:10-11
  • 예시 2 (가족/세대 통합)
  • 메인 타이틀: 별빛 아래 모인 우리
  • 서브 타이틀: 예수님의 탄생을 함께 기뻐하는 성탄 음악회
  • 성구: 마태복음 2:10-11
  • 예시 3 (기대/설렘 강조)
  • 메인 타이틀: 다시 오실 왕, 예수님
  • 서브 타이틀: 우리 마음의 가장 낮은 곳으로 오신 아기 예수님
  • 성구: 요한복음 1:14

3. 포스터 디자인 및 배치 팁

시각적 위계(Hierarchy) 설정

  1. 가장 중요한 정보(제목): 포스터 전체 면적의 1/3을 차지하게 합니다. 눈에 가장 먼저 들어와야 합니다.
  2. 보조 정보(부제 및 성구): 제목 하단에 배치하며, 제목보다는 작은 폰트를 사용합니다.
  3. 핵심 정보(일시/장소): 가독성이 중요합니다. 굵은 고딕 계열의 폰트를 추천합니다.
  4. 연락처/문의: 포스터 하단 1/4 지점에 배치하여 정보의 마무리가 되도록 합니다.

배치 체크리스트

  • 여백의 미: 정보를 꽉 채우지 마십시오. 정보와 정보 사이에 충분한 여백을 두어 답답하지 않게 합니다. (확인 필요: 모바일 폰으로 보았을 때 글자가 작아지지는 않는지)
  • 색상 대비: 배경색이 어두우면 글자는 밝게(흰색), 배경색이 밝으면 글자는 어둡게(검정, 남색) 배치하여 가독성을 높입니다.
  • 이미지 활용: 저작권 무료 이미지 사이트(Unsplash, Pixabay 등)를 활용하되, 교회의 분위기와 어울리는 따뜻하고 밝은 톤의 사진을 권장합니다.
  • 로고 삽입: (교회명) 로고나 마크가 있다면 우측 상단이나 하단 구석에 작게 배치하여 공신력을 확보합니다.

4. 최종 점검 리스트 (인쇄 전 필수)

  1. [ ] 오타 확인: 일시(날짜와 요일 일치 여부), 장소, 문의 전화번호가 정확한가?
  2. [ ] 성경 구절 확인: 성경 인용 시 장절 표기가 정확한가? (문맥에 맞는지 확인 필요)
  3. [ ] 연락처 연결: 안내된 번호로 직접 전화를 걸어 연결이 잘 되는지 확인했는가?
  4. [ ] 이미지 저작권: 무단 사용된 이미지는 없는가? (확인 필요)
  5. [ ] 시각적 균형: 먼 거리(예: 예배당 입구 복도)에서 보았을 때 제목이 바로 읽히는가?
