3. 규모별 핵심 전략

A. 20명 이하 (소규모)

  • 전략: 관계 중심의 '가족 같은 분위기'를 형성하는 것이 최우선입니다.
  • 장점: 이동의 유연성, 비용 절감, 깊이 있는 신앙 상담 가능.
  • 체크포인트:
  • ( ) 장소 섭외: 교인의 별장이나 작은 기도원을 활용하여 비용 절감.
  • ( ) 식단: 외부 사 먹기보다는 직접 요리하여 공동체 의식 함양.
  • ( ) 차량: 보험 가입 여부 및 운전자 면허 확인 필수.

B. 20~60명 (중규모)

  • 전략: 체계적인 일정을 통해 '집중력 있는 훈련'을 지향합니다.
  • 장점: 외부 환경 전환을 통한 신앙적 몰입도 향상.
  • 체크포인트:
  • ( ) 강사 섭외: 외부 강사 초빙 시 사례비 및 이동 수단 사전 조율.
  • ( ) 프로그램: 레크리에이션 등 외부 진행자 섭외 고려 (필요 시).
  • ( ) 안전: 시설 자체 화재 보험 및 배상 책임 보험 가입 여부 확인 (확인 필요).

C. 60명 이상 (대규모)

  • 전략: '시스템과 분업'을 통한 안전하고 안정적인 운영이 핵심입니다.
  • 장점: 대규모 집회의 영적 경험 제공, 행사 전문성 확보.
  • 체크포인트:
  • ( ) 조직 구성: 기획팀, 찬양팀, 안전팀, 식당/관리팀으로 세분화.
  • ( ) 계약: 시설 사용 계약서 작성 시 위약금 규정 확인.
  • ( ) 인프라: 음향 장비 및 영상 장비 사전 점검 (현장 사양 확인 필요).

5. 평신도 리더를 위한 조언

  1. 안전은 최우선: 어떠한 프로그램보다 '안전'이 무너지면 모든 사역이 중단됩니다. 반드시 시설의 안전 검사를 확인하고, 응급 상황 매뉴얼을 숙지하십시오.
  2. 기도의 준비: 행사 준비보다 중요한 것은 교사들의 기도회입니다. 준비 기간 중 주 1회 교사 기도회를 정례화하십시오.
  3. 기록 보존: 모든 행사는 사진과 영상으로 남겨 주보나 교회 홈페이지, SNS에 게시하여 교인들과 기쁨을 공유하십시오.
  4. 말씀 중심: 규모가 작든 크든, 우리 교단의 신학적 정체성(말씀과 성령의 조화)을 잃지 않도록 성경 공부 시간을 반드시 확보하십시오.
