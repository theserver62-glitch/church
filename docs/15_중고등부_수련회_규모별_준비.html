규모별 준비 방식 비교

※ 규모는 학생 수 기준이며, 경계 인원인 20명·60명은 교사 수와 장소 여건에 따라 유형을 선택한다. 예산은 1박 2일, 학생·교사 전체 참가자 기준의 편성 예시이며 실제 견적은 별도 확인한다.

규모별 체크리스트

1) 20명 이하

  • [ ] 교회 숙박과 외부 숙소의 비용·안전·교사 부담을 비교했다.
  • [ ] 교사가 부족하면 당일형 또는 연합수련회로 조정했다.
  • [ ] 식사 준비 중에도 학생을 돌볼 교사를 확보했다.
  • [ ] 차량별 탑승자와 출발·도착 확인 담당을 정했다.
  • [ ] 교사와 학생의 성별을 고려해 숙소·세면 공간을 배치했다.
  • [ ] 프로그램을 말씀·관계·쉼 중심으로 간결하게 정했다.

2) 20~60명

  • [ ] 조 편성과 조별 담당 교사를 미리 정했다.
  • [ ] 진행·회계·급식·안전 담당의 역할을 나누었다.
  • [ ] 조별 나눔 자료와 진행 순서를 교사에게 공유했다.
  • [ ] 예배·활동·식사 사이에 이동과 인원 확인 시간을 넣었다.
  • [ ] 버스 좌석 수와 전체 참가자 수를 대조했다.
  • [ ] 장소 예약금·잔금·환불 기한을 기록했다.

3) 60명 이상

  • [ ] 총괄 담당과 예배·생활·차량·급식·안전 책임자를 정했다.
  • [ ] 시설 수용 인원과 프로그램별 활동 가능 인원을 확인했다.
  • [ ] 차량별 명단·인솔자·연락 체계를 마련했다.
  • [ ] 조별 이동 경로와 식사·샤워 이용 시간을 나누었다.
  • [ ] 응급 상황에서도 나머지 학생을 돌볼 인력을 확보했다.
  • [ ] 학생 실종·화재·부상 발생 시 역할과 집결지를 공유했다.
  • [ ] 전체 교사 사전 모임과 현장 동선 점검을 실시했다.
  • [ ] 연합수련회 참여 시 주최 측과 교회의 책임 범위를 확인했다.
