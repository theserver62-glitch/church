목적 : 부활의 기쁨을 배우고 달걀 꾸미기와 이웃 나눔으로 사랑을 실천한다.

특별활동

1) 달걀 꾸미기·나눔

  • 교사가 준비한 완숙 달걀의 포장 상자를 스티커로 꾸민다.
  • 달걀은 교사가 집게로 담고, 학생은 카드와 포장을 맡는다.
  • 달걀 알레르기 학생은 종이 달걀을 꾸미며, 식품 접촉 없이 참여한다.

2) 부활 이야기 활동

  • 마태복음 28:1–10을 함께 찾아보고 그림 카드를 순서대로 놓는다.
  • “예수님의 부활이 기쁜 이유”를 말하거나 그림으로 표현한다.
  • 어린 학생은 교사와 짝을 이루어 참여한다.

3) 이웃 나눔

  • 나눔 대상·수량 : ________ / ________개
  • 사전 연락·수령 동의 확인 담당 : ________
  • 전달 장소·시간 : ________ / ________
  • 학생은 교사와 조별로 이동하고, 출발·도착 때 인원을 확인한다.
  • 방문이 어려우면 교회에서 전달한다. 사진 촬영은 동의를 받은 경우에만 한다.

알레르기·위생 주의

  • 신청 시 달걀 및 기타 식품 알레르기를 보호자에게 확인하고 담당 교사끼리 공유한다.
  • 대체 나눔품 : ________ / 성분 표시 확인 담당 : ________
  • 달걀은 충분히 익혀 냉장 보관하고, 이동 시 보냉 가방을 사용한다.
  • 금이 가거나 보관 상태가 불분명한 달걀은 사용하지 않는다.
  • 포장에 달걀 함유 여부·준비 일시·냉장 보관 안내를 적는다.
  • 섭취 후 이상 반응이 있으면 즉시 활동을 멈추고 보호자에게 연락한다. 호흡곤란 등 응급 증상이 있으면 119에 신고한다.
