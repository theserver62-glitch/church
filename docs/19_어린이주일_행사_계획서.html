특별활동

1) 어린이 축복 기도·선물 전달

어린이가 원하는 기도 제목을 말하거나 카드에 적는다. 기도 담당자가 이름을 부르며 건강·가정·학교생활·믿음의 성장을 위해 짧게 기도한다. 신체 접촉은 어린이의 의사를 존중한다. 같은 선물을 준비하고 미참석 어린이 전달 담당을 정한다.

  • 선물 품목 : ________ / 포장 담당 : ________ / 미참석자 전달 : ________

2) 부모 초청 순서

초청 안내 발송 → 참석 회신 확인 → 예배 동석 → 어린이 감사 인사 → 보호자의 축복 한마디 → 가족 축복 카드 작성 순으로 진행한다. 보호자가 참석하지 못한 어린이는 교사와 함께 참여한다.
